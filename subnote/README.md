# subnote

구독 서비스, 결제 일정, 결제 수단별 예상 지출을 관리하는 한국어 반응형 웹앱입니다. 기존 가사 타이머와 별도 폴더 및 저장 키를 사용합니다.

## 실행

`index.html`을 브라우저에서 열거나, 프로젝트 루트에서 `node subnote/server.cjs`를 실행하고 `http://localhost:4173`에 접속합니다. 별도 의존성이나 빌드가 없습니다.

## 기능

- 대시보드, 구독 목록, 월별 캘린더, 결제 수단별 합계
- 월간·연간 구독 추가, 수정, 삭제 및 검색·카테고리 필터
- 결제일이 없는 짧은 달에는 말일에 결제 예정으로 표시
- localStorage 저장, JSON 내보내기
- 반응형 모바일 하단 내비게이션, 웹앱 매니페스트, 오프라인 앱 화면 캐시

첫 화면의 6개 서비스는 샘플입니다. `새로 시작하기`를 누르면 목록을 비우고 실제 구독을 등록할 수 있습니다. 데이터는 이 브라우저에만 저장되며, 브라우저 데이터 삭제 시 사라집니다. 지출은 등록된 일정에 따른 예상액이며 실제 카드 승인 내역이 아닙니다. 과거 차트도 현재 구독 설정으로 다시 계산됩니다.

## 묶음 구독 (2026-10-01 확인)

구독 추가에서 상품 카드를 선택하면 카페 주문 옵션처럼 기본 혜택, 단일 선택 콘텐츠, 별도 연동 혜택이 펼쳐집니다. 선택 내용은 구독과 함께 저장되고 수정 및 JSON 내보내기에 포함됩니다. 구독 목록의 `묶음 혜택`을 펼쳐 확인할 수 있습니다.

- 네이버플러스: MYBOX 80GB·웹툰 쿠키 10개 기본 제공, 디지털 콘텐츠 택 1, Uber One 12개월 무료 연동 기록. 월 4,900원·연 46,800원은 공식 안내 기준 제안값이며 실제 금액으로 수정할 수 있습니다.
- 배민클럽: 일반 상품과 YouTube Premium 결합상품을 구분합니다. YouTube 공식 파트너 목록에서 우아한형제들을 확인했습니다. 현재 결합상품 요금과 상세 가입 조건은 공개 공식 페이지에서 확인하지 못했으므로 자동 입력하지 않습니다. 배민 앱의 전체 결제액을 입력합니다.
- Google AI Pro: 공식 안내상 Drive·Gmail·포토 공용 5TB입니다. 한국 계정별 실제 청구액은 직접 입력합니다.

정보와 출처 링크는 `bundles.js`에 분리되어 있으며 **실시간 자동 수집은 아닙니다**. UI에서 정보 확인일과 공식 출처를 제공합니다. 카탈로그는 향후 수동 갱신할 수 있습니다. 제휴 서비스의 실제 가입·연동은 수행하지 않습니다.

포함 혜택은 별도 결제 구독을 생성하지 않으며, 사용자가 입력한 부모 구독 전체 금액만 합산합니다. 기존 독립 구독과 겹치면 안내하되 삭제하거나 지출에서 자동 제외하지 않습니다. Uber 무료 혜택 종료일은 별도 연동 시작일로 계산하며, 종료 후 유료 요금을 자동으로 추정·추가하지 않습니다.

## 다음 확장 계획

로그인·기기 간 동기화, 실제 결제 기록 보관, 결제 알림, 데이터 가져오기는 아직 구현하지 않았습니다. 카드 연동은 별도 인증 및 서버 구성이 필요합니다. 현재는 카드 별칭만 저장합니다. 매니페스트와 서비스 워커를 포함했으며, 모바일 설치 지원은 브라우저별 확인과 배포용 PNG 아이콘 보완이 필요합니다. 오프라인 캐시는 localhost 또는 HTTPS에서 동작합니다.

### 서비스별 요금제 카탈로그
- `catalog.js`: 2026-10-01 공식 사이트 확인 스냅샷. 서비스별 요금제 ID, 용량, 통화, 월/연 실제 결제액, 출처를 관리합니다. 실시간 API 또는 자동 갱신 DB는 아닙니다.
- iCloud+, Netflix, Spotify, YouTube Premium, Notion, Figma, 네이버플러스, 배민클럽, Google AI Pro 지원. YouTube 가격 출처는 공식 제휴사 SK브로드밴드 안내입니다.
- 서비스 → 요금제 선택 시 확인된 원화 가격을 반영합니다. Notion은 좌석 수를 곱하고, 연간 결제는 월 환산액이 아닌 연간 총액을 저장합니다.
- Figma는 USD 가격만 표시하고 실제 원화 청구액은 수동 입력합니다. 배민클럽 및 미확인 결제 주기 가격도 수동 입력합니다. 무료 체험/기간 한정 프로모션은 기본 가격에 적용하지 않습니다.
- 기존 구독을 열 때 금액을 덮어쓰지 않습니다. 요금제 변경 또는 공식 요금 적용 버튼을 눌러야 변경됩니다. 할인 금액은 직접 수정할 수 있습니다.
- 저장 시 `plan`에 요금제·용량·좌석·통화·공식 가격·출처·확인일을 보관하고 `amount`에는 실제 원화 결제액을 보관합니다. 지출에는 실제 결제액만 합산합니다.
- 확인: `node test.cjs`. 브라우저에서 iCloud 50GB/200GB 가격 변경, 사용자 금액 수정 후 저장/새로고침, 기존 데이터 금액 보존을 검증했습니다.
